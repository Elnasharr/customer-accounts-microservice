# Customer Accounts Microservice

![CI Build Status](https://github.com/Elnasharr/customer-accounts-microservice/actions/workflows/ci-build.yaml/badge.svg)

## Project Overview
This capstone project involves the development, testing, and continuous deployment of a cloud-native Customer Accounts microservice. The service implements RESTful APIs, secure headers, automated testing pipelines, and containerized deployment via Docker and Kubernetes.
